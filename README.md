# Real Estate Intelligence

A machine learning platform for residential real estate price prediction, market analysis, explainable AI, and similar property search in Bucharest.

## Project Overview

This project aims to develop an end-to-end machine learning system for analyzing the residential real estate market in Bucharest.

The platform will combine data analysis, feature engineering, machine learning, explainability, and an interactive application.

## Main Features

- Residential property price prediction
- Price per square meter analysis
- Real estate market analysis
- Similar property search
- Model explainability
- Prediction uncertainty
- Interactive dashboard

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- SHAP
- Plotly
- Streamlit
- FastAPI
- Docker
